# 🎬 Netflix Clone (HTML & CSS Only)

A responsive, pixel-perfect front-end UI recreation of the Netflix web interface built completely with HTML5 and CSS3.

## ✨ Features
* **Hero Banner:** Dark overlay gradient with styled call-to-action buttons.
* **Movie Rows:** Custom horizontal scrolling containers for movie thumbnails.
* **Hover Micro-Interactions:** Smooth CSS scale transforms on movie posters.
* **Fully Responsive:** Layout adapts seamlessly from desktop screens down to mobile devices using CSS Media Queries.

## 🛠️ Built With
* HTML5
* CSS3 (Flexbox, CSS Grid, Transitions)
